# The Old Bakery Tearoom

## Project Overview

The Old Bakery Tearoom is a fictional local café website created as part of Project 2. The website is designed to promote a local tearoom, provide information about its background and values, display its menu and featured products, and allow customers to get in touch.

The website has a welcoming and easy-to-use design, with clear navigation and a consistent layout across all five pages.

## Purpose and User Value

The purpose of this website is to give customers an online place where they can learn about The Old Bakery Tearoom before visiting.

The website allows users to:
- Find out about the tearoom and its background.
- Read about the tearoom's values.
- Browse the food and drinks menu.
- View featured products and their prices.
- Find contact details and opening hours.
- Use the contact form to enter a message.

## Technologies Used

The website was created using:

- **HTML5** – used to structure the website pages.
- **CSS3** – used to style the website and create a consistent layout.
- **JavaScript** – used to add interactive features.
- **Visual Studio Code** – used as the code editor.
- **Git and GitHub** – used for version control and storing the project.
- **GitHub Pages** – used to publish the website online.

## Website Features

### Home Page

The home page introduces The Old Bakery Tearoom and gives visitors an overview of the café. It highlights what makes the tearoom special and provides navigation to the other pages.

### About Page

The about page provides information about the tearoom's background, its values and what customers can expect when visiting.

### Menu Page

The menu page displays the food and drinks available at the tearoom.

It includes:
- Coffee.
- Other drinks.
- Snacks.
- Product images and descriptions.
- Prices for each item.
- Filter buttons to help users browse the menu.
- A sample basket that displays the number of items and total price.
- A clear basket option.

### Products Page

The products page highlights a featured product, the Classic Cappuccino.

It includes:
- A product image.
- A product description.
- The product price of £3.40.
- Additional product information.
- An option to add the product to the sample basket.

### Contact Page

The contact page provides visitors with the tearoom's contact information.

It includes:
- Address: 12 Market Street, Yourtown, UK.
- Email: hello@thedailygrind.example.
- Telephone: 01234 567890.
- Opening hours.
- A contact form for visitors to enter their details and message.

## Deployment

The website can be published using GitHub Pages.

To publish the website:

1. Upload the project files to a GitHub repository.
2. Open the repository settings.
3. Select **Pages**.
4. Choose the main branch as the publishing source.
5. Save the settings.
6. Open the website using the GitHub Pages link provided.

## Limitations

The website is a fictional café website created for an educational project.

The sample basket is intended to demonstrate website interaction and does not process real orders or payments.

The contact form is a demonstration and does not send or store messages unless a suitable form-processing service is connected.
